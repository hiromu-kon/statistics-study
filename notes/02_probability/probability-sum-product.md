# 確率の和と積

## このノートで学ぶこと

このノートでは、確率の基本である「和」と「積」を整理します。

ざっくり言うと、次のように使い分けます。

```text
AまたはBが起こる → 確率の和
Aが起きて、さらにBが起こる → 確率の積
```

ただし、いつでも単純に足したり掛けたりできるわけではありません。

```text
和を使うときは、排反かどうか
積を使うときは、独立かどうか
```

を確認します。

## 1. 確率の基本用語

### 試行

確率的な実験のことです。

例:

```text
サイコロを投げる
コインを投げる
くじを引く
```

### 事象

試行によって起こる出来事のことです。

例:

```text
サイコロを投げて1の目が出る
コインを投げて表が出る
くじを引いて当たりが出る
```

### 排反

一方が起きたら、もう一方は同時に起きない関係のことです。

例:

```text
サイコロを1回投げるとき、1の目が出る
サイコロを1回投げるとき、2の目が出る
```

1回のサイコロで、1と2が同時に出ることはありません。

なので、この2つの事象は排反です。

### 独立

一方の結果が、もう一方の結果に影響しない関係のことです。

例:

```text
コインを1回目に投げて表が出る
コインを2回目に投げて表が出る
```

1回目の結果は、2回目の結果に影響しません。

なので、この2つの事象は独立です。

### 同様に確からしい

起こりうるすべての結果が、同じくらい起こりそうだと考えられることです。

例:

```text
普通のサイコロなら、1, 2, 3, 4, 5, 6 のどの目も同じくらい出そう
```

このようなとき、「同様に確からしい」といいます。

## 2. 確率の性質

確率は、0から1の間の数で表します。

```text
全く起こらない確率 = 0
必ず起こる確率 = 1
```

たとえば、普通のサイコロを1回投げる場合を考えます。

```text
7の目が出る確率 = 0
1から6のどれかが出る確率 = 1
```

## 3. 確率の和

確率の和は、「AまたはBが起こる」確率を考えるときに使います。

ただし、ここで単純に足せるのは、AとBが排反のときです。

```text
AとBが排反なら、
AまたはBが起こる確率 = Aが起こる確率 + Bが起こる確率
```

例:

```text
サイコロを1回投げる
A: 1の目が出る
B: 2の目が出る
```

このとき、AとBは同時に起こりません。

つまり排反です。

なので、

```text
1または2の目が出る確率
= 1の目が出る確率 + 2の目が出る確率
= 1/6 + 1/6
= 2/6
= 1/3
```

## 4. 確率の積

確率の積は、「Aが起きて、さらにBが起こる」確率を考えるときに使います。

ただし、ここで単純に掛けられるのは、AとBが独立のときです。

```text
AとBが独立なら、
Aが起きて、さらにBが起こる確率 = Aが起こる確率 × Bが起こる確率
```

例:

```text
コインを2回投げる
A: 1回目に表が出る
B: 2回目に表が出る
```

1回目の結果は、2回目の結果に影響しません。

つまり独立です。

なので、

```text
1回目も表、2回目も表の確率
= 1回目に表が出る確率 × 2回目に表が出る確率
= 1/2 × 1/2
= 1/4
```

## 5. 和と積の見分け方

まず、日本語の意味で考えます。

```text
AまたはB → 和を考える
AかつB → 積を考える
```

そのうえで、条件を確認します。

```text
和で単純に足してよいか → 排反かどうか
積で単純に掛けてよいか → 独立かどうか
```

## 6. よくある勘違い

### 「または」なら必ず足せるわけではない

排反でない場合、単純に足すと重なっている部分を2回数えてしまいます。

この場合は、重なりを引く必要があります。

### 「かつ」なら必ず掛けられるわけではない

独立でない場合、単純に掛けることはできません。

この場合は、条件付き確率を考える必要があります。

## 7. 今日の理解

- 排反は「同時に起こらない」
- 独立は「一方がもう一方に影響しない」
- 確率の和は「または」
- 確率の積は「かつ」
- ただし、足す前に排反か、掛ける前に独立かを確認する
