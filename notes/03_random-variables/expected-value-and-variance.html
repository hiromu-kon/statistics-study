期待値と分散

期待値は「長い目で見た平均」、分散は「どれくらい散らばるか」です。

まず一言で

期待値は、確率変数が平均的にどれくらいの値になりそうかを表します。

分散は、値が期待値からどれくらい離れやすいかを表します。

1. 期待値とは

期待値は、「その試行を何度も何度も繰り返したときの平均」のようなものです。

たとえば、普通のサイコロを1回投げて、出た目を X とします。

Xの値確率
11/6
21/6
31/6
41/6
51/6
61/6

期待値は、値に確率をかけて足し合わせます。

E(X)
= 1 × 1/6 + 2 × 1/6 + 3 × 1/6 + 4 × 1/6 + 5 × 1/6 + 6 × 1/6
= 21/6
= 3.5

サイコロの目に3.5はありません。それでも、何度も投げたときの平均は3.5に近づきます。

2. 期待値の公式

確率変数 X が値 x をとる確率を P(X=x) と書くと、期待値は次のように表します。

E(X) = 値 × 確率 を全部足す

E(X) = x1 × P(X=x1) + x2 × P(X=x2) + ...

読み方としては、「それぞれの値を、起こりやすさで重みづけして平均する」です。

3. 分散とは

分散は、値が期待値からどれくらい散らばっているかを表す量です。

期待値だけでは、ばらつきがわかりません。

あまり散らばらない例

3, 3, 4, 4

平均は3.5。値は平均の近くにあります。

大きく散らばる例

1, 1, 6, 6

平均は3.5。でも値は平均から遠いです。

どちらも平均は3.5ですが、散らばり方は違います。この違いを見るために分散を使います。

4. 分散の考え方

分散は、ざっくり次の手順で考えます。

  1. 期待値からどれくらい離れているかを見る。
  2. 離れ具合を2乗する。
  3. それを確率で重みづけして足す。

V(X) = E((X - E(X))^2)

X - E(X) は「期待値からのズレ」です。

2乗するのは、プラスのズレとマイナスのズレが打ち消し合わないようにするためです。

分散がある意味

ズレをそのまま足すと、プラスのズレとマイナスのズレが打ち消し合うことがあります。

平均が5のとき
10のズレ: 10 - 5 = 5
0のズレ: 0 - 5 = -5

5 + (-5) = 0

これだと、実際には平均から離れているのに「ズレがない」ように見えてしまいます。

そこでズレを2乗して、ズレの大きさとして扱います。

5^2 = 25
(-5)^2 = 25

これが分散の基本的な意味です。

5. サイコロの分散

サイコロの期待値は 3.5 でした。

それぞれの目について、期待値からのズレを2乗します。

XX - 3.5(X - 3.5)^2確率
1-2.56.251/6
2-1.52.251/6
3-0.50.251/6
40.50.251/6
51.52.251/6
62.56.251/6
 
V(X)
= 6.25×1/6 + 2.25×1/6 + 0.25×1/6 + 0.25×1/6 + 2.25×1/6 + 6.25×1/6
= 17.5 / 6
= 35 / 12

6. よく使う別公式

分散は次の形でも計算できます。

V(X) = E(X^2) - {E(X)}^2

これは計算を楽にするためによく使います。

意味としては、「2乗の平均」から「平均の2乗」を引く、という形です。

7. 標準偏差とは

標準偏差は、分散の平方根です。

標準偏差 = √分散

記号では、分散を V(X) と書くと、標準偏差は次のように書けます。

√V(X)

分散はズレを2乗しているので、単位も2乗されたような形になります。

標準偏差は平方根をとることで、もとのデータと同じ感覚で散らばりを見やすくします。

例

分散が25なら、標準偏差は次の通りです。

√25 = 5

これは、「だいたい平均から5くらいズレる」と読むための目安になります。

ずれと標準偏差は同じではない

ずれは、1つ1つの値が平均からどれくらい離れているかです。

標準偏差は、全体として平均からだいたいどれくらい散らばっているかを表します。

ずれ: 各データごとの平均との差
分散: ずれを2乗して平均したもの
標準偏差: 分散の平方根

つまり、標準偏差は「平均からの典型的なズレの大きさ」と考えるとわかりやすいです。

覚えておくポイント

  • 期待値は、長い目で見た平均。
  • 期待値は、値に確率をかけて足す。
  • 分散は、期待値からのズレの大きさを見る。
  • 分散ではズレを2乗する。
  • 標準偏差は、分散の平方根。
  • 標準偏差は、もとのデータと同じ感覚で散らばりを見るために使う。
  • 平均が同じでも、分散が違うことがある。
