# 統計検定2級 学習リポジトリ

統計検定2級の合格を目指して、中学数学からやり直すための学習リポジトリです。ゆくゆくは1級まで目指します。学習サイトには準1級・1級のコースの枠も用意してあります。

学習の中心は `site/` の **学習サイト「統計検定ノート」** です。いまは2級の出題範囲表に沿って、中学数学の復習から線形モデルまでを、図・動かせるグラフ・確認問題つきでまとめています。学習ログや疑問メモ（Markdown）はこのリポジトリに残し、サイトの「学習ログ」ページからも読めます。

## 学習サイトの起動

```sh
cd site
npm install
npm run dev
```

ブラウザで表示された URL（`http://localhost:5173`）を開きます。詳しくは [site/README.md](site/README.md) を参照してください。

| ページ | 内容 |
| --- | --- |
| 教科書 | 章ごとのレッスン。読み終えたら「読み終えた」を押すと進み具合が記録される |
| 問題演習 | 章・難しさ・解いた状況で絞り込んで解く |
| 模擬試験 | 本番と同じ1問あたりの時間で、まとめて採点する |
| 復習リスト | サイトの問題で直近に間違えたものが自動でたまる |
| 公式集・用語集・分布表 | 式の意味、用語の言い換え、標準正規分布表・t分布表など |
| 学習ログ | このリポジトリの Markdown（学習ログ・疑問・ミス・言い換え・目標）を表示する |

## 現在の前提

- 開始日: 2026-07-22
- 数学の出発点: 中学数学もあまり覚えていない状態から再スタート
- 目標: 統計検定2級に合格する（詳しくは [roadmap/goals.md](roadmap/goals.md)）

## 毎回の学習の流れ

1. 学習サイトのレッスンを章の順に読み、確認問題を解く
2. その日にやったことを `learning-log/` に雑に書く
3. わからないことは `questions/unresolved.md` に残す。解決したら `questions/resolved.md` に移す
4. 難しい用語は `glossary/` で自分の言葉に言い換える
5. 公式問題集などサイトの外で解いた問題のミスは `mistakes/grade2.md` に残す（サイトの問題のミスは復習リストに自動でたまる）

## ディレクトリ構成

```text
statistics-study/
  README.md
  AGENTS.md                 # AIエージェント向けの作業ルール（CLAUDE.md はこのファイルへのリンク）

  site/                     # 学習サイト（教材・問題・公式集・用語集・分布表）← 学習の中心

  roadmap/
    goals.md                # 目標と合格までの到達ライン

  learning-log/             # 日々の学習ログ（月ごとのファイル）
    README.md               # 書き方
    2026/

  questions/                # 疑問メモ
    unresolved.md           # まだわからないこと
    resolved.md             # 解決したこと

  mistakes/
    grade2.md               # サイトの外で解いた問題のミス

  glossary/                 # 自分の言葉での言い換え
    terms.md
    easy-explanations.md

  references/               # 使った教材（書籍・Webサイト・YouTube）
```

## AIとの使い方

AIに聞くときは、なるべくこのリポジトリの文脈を渡します。

```text
この unresolved.md を見て、今の疑問を初学者向けに整理してください。
```

```text
このミスノートを見て、次に復習すべき学習サイトのレッスンを優先順位付きで出してください。
```

## 著作権について

問題集・過去問・動画教材の内容をそのまま転載しません。記録するのは、自分の解答、自分の間違い方、自分の理解、参照元の情報に留めます。
